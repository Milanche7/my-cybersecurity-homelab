# Screenshot Plan & Privacy Checklist

This folder is intentionally empty of screenshots until I can share real evidence without exposing information from my home network.

## Planned evidence

- Proxmox overview and VM list (private node names, IPs and user information hidden)
- Virtual bridge overview showing logical separation, without real subnet ranges
- OPNsense zone/interfaces overview, with real addresses and identifiers redacted
- Windows domain / Group Policy verification, with domain and account details hidden
- Wazuh endpoint telemetry, with event fields and host identifiers checked
- Suricata's SSH scan alert, with source/destination network information hidden
- Wazuh view of the corresponding network alert, sanitized in the same way

## Before publishing any screenshot

- [ ] Hide **all** real IP addresses, subnets, domain names and MAC addresses.
- [ ] Hide usernames, email addresses, account IDs, unique hostnames, internal URLs and VPN device names.
- [ ] Hide secrets, credentials, API tokens, QR codes and recovery codes.
- [ ] Check browser tabs, the URL bar, bookmarks, terminal history and notification pop-ups.
- [ ] Review metadata and filenames for identifying information.
- [ ] Use a solid opaque mask or crop instead of a reversible blur.
- [ ] Open the final image at full resolution and check it again before upload.

No screenshots have been included in the initial release. A blank folder is intentional.
