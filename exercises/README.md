# Home Lab Exercises

This directory is where I will keep **individual, documented, authorized attack-and-defense exercises** as I use the finished infrastructure. The first confirmed scan-to-alert path is described in the main [README](../README.md); it is not presented as a full incident-response case study.

My aim is to capture not just commands, but what I expected to happen, what actually happened, what evidence was available, and what I learned.

## Planned focus areas

1. Network discovery and Suricata alert triage
2. Windows event and Sysmon investigations in Wazuh
3. Active Directory administration and security validation
4. Comparing network and endpoint visibility in the same controlled scenario
5. Basic SOC reports and incident-response workflow practice

I will use [TEMPLATE.md](TEMPLATE.md) for each write-up. Exercises are carried out only against assets I control or have authorization to test. Screenshots and logs will be sanitized before publishing.
